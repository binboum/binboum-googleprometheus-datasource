# Security Policy

## Supported versions

Only the latest minor release receives security fixes. There is no backport
policy for older minors.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |
| < 0.1   | ❌        |

## Reporting a vulnerability

Please report security issues privately by email to **maxence@laude.pro**.
Do not open a public GitHub issue for a vulnerability.

Include the affected version, a description of the issue, and reproduction
steps. Do not include service-account keys, access tokens, or other live
credentials in your report.

You can expect an acknowledgement within **7 days**. Once a fix is available it
will ship in the next patch release and be noted in
[CHANGELOG.md](CHANGELOG.md).

No PGP key is published for this project.
